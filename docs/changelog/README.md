# Changelog

What each release of FL26 Mod Studio brought. The full notes of the latest releases:

- [0.2.3](changelog-0.2.3.md) (2026-10-13): a quick fix for 0.2.2 -- Mod Studio no longer closes
  during Build; it shows the builder's message instead, a crash writes crash.log, and Build
  finds the game in the folder from Settings (not only C:\Football Life 2026).
- [0.2.2](changelog-0.2.2.md) (2026-10-13): the big fix update, with raised limits (2,400 clubs,
  up to 97 new leagues). Careers saved before 0.2.2 do not load: start a new one after Build.
- [0.2.1](changelog-0.2.1.md) (2026-10-10): a quick interim update that fixes the Master League /
  Be a Legend crash of the 0.2.0 package.
- [0.2.0](changelog-0.2.0.md) (2026-10-08): the last release with new features. From here on:
  bug fixes, about once a week.

The release notes of every version are also on the
[Releases](https://github.com/Matozanato/FootballLife-new-leagues/releases) page.
