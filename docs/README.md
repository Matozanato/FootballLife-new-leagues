# FL26 Mod Studio documentation

## Where to start

The guides for players are in [guides/](../guides/README.md), one folder per language (English,
hrvatski, español, português; the Mod Studio guide also in français):

- [Install a ready pack](../guides/en/install-a-pack.md): pick this when someone gave you a world,
  a modpack or a `.fl26pack` league package.
- [Make your own leagues and packs](../guides/en/make-your-own-leagues.md): pick this when you
  want to choose real leagues from the NewLife Database, set them up yourself and share them.

## For players

- [Mod Studio guide](../guides/en/mod-studio-guide.md): every page of Mod Studio, explained
  (other languages: [guides/](../guides/README.md)).
- [faq.md](faq.md): the questions people ask (updating, crashes at start, cups, promotion, what
  to send when something is wrong).
- [known-issues.md](known-issues.md): what works, what does not yet, and what was fixed.

## Folders

- [changelog/](changelog/README.md): what each version brought, and the full notes of the latest
  releases.
- [developers/](developers/for-developers.md): for modders and developers. Forks and pull
  requests ([forking.md](developers/forking.md) and its chapters in
  [developers/fork/](developers/fork/)), how Mod Studio works and the league package format
  ([mod-studio.md](developers/mod-studio.md)), the manual route with Python
  ([by-hand.md](developers/by-hand.md)) and the [testing guide](developers/testing-guide.md).
- [research/](research/research-findings.md): how the game was taken apart. The research log
  ([research-findings.md](research/research-findings.md)), [how it works](research/how-it-works.md),
  [limits and numbers](research/limits.md), the [league phase decode](research/league-phase-swiss-decode.md)
  and the [player record](research/player-record.md).

Help and new versions: the [Discord](https://discord.gg/StQqtk3G3M). Bugs: a
[GitHub issue](https://github.com/Matozanato/FootballLife-new-leagues/issues).
